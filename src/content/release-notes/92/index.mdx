This article provides information about the changes in Firefox 92 that will affect developers. Firefox 92 was released on September 7, 2021.

## Changes for web developers

### HTML

No changes

### CSS

- The keywords `avoid-page` and `avoid-column` are now supported for the [`break-inside`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/break-inside) property ([Firefox bug 1722945](https://bugzil.la/1722945)).
- The two-value syntax for the [`font-size-adjust`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/font-size-adjust) property is now supported ([Firefox bug 1720131](https://bugzil.la/1720131)).
- The [`size-adjust`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@font-face/size-adjust) descriptor is now supported ([Firefox bug 1720131](https://bugzil.la/1720131)).
- The CSS [`accent-color`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/accent-color) property has been implemented ([Firefox bug 1722031](https://bugzil.la/1722031)).
- The `system-ui` value is now supported for the [`font-family`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/font-family) property ([Firefox bug 1226042](https://bugzil.la/1226042)).

### JavaScript

- [`Object.hasOwn()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Object/hasOwn) can be used to test whether a property was defined on an object or inherited ([Firefox bug 1721149](https://bugzil.la/1721149)).
- The default 5MB storage quota is now available to each origin. The quota previously applied to an entire domain group (also known as [registrable domain](https://developer.mozilla.org/en-US/docs/Glossary/Registrable_domain); e.g., `*.wikipedia.org`). ([Firefox bug 1064466](https://bugzil.la/1064466)).
- Storage quotas for [`Window.localStorage`](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage) are now shared with [IndexedDB API](https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API) and [`Cache`](https://developer.mozilla.org/en-US/docs/Web/API/Cache) ([Firefox bug 742822](https://bugzil.la/742822)).

### HTTP

- Firefox will automatically upgrade an HTTP request to HTTPS when a usable [HTTPS RR](https://developer.mozilla.org/en-US/docs/Glossary/HTTPS_RR) is available.
  It will also use information provided in an _HTTPS RR_ to optimize the process of establishing HTTPS connections⁠—this is conceptually similar to using the [`Alt-Svc`](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Alt-Svc) header.
  ([Firefox bug 1721132](https://bugzil.la/1721132)).

### APIs

- The `disabledFeatures` static property has been implemented for Custom Elements ([Firefox bug 1723396](https://bugzil.la/1723396)).

#### DOM

- The [Imperative Slotting API](https://developer.mozilla.org/en-US/docs/Web/API/HTMLSlotElement) (part of the [Shadow DOM API](https://developer.mozilla.org/en-US/docs/Web/API/Web_components/Using_shadow_DOM)) Has been implemented. ([Firefox bug 1705141](https://bugzil.la/1705141))
- You can now monitor for changes to text selections in [`<input>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input) or [`<textarea>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/textarea) by listening for `selectionchange` events in [`HTMLInputElement`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLInputElement/selectionchange_event) and [`HTMLTextAreaElement`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLTextAreaElement/selectionchange_event), respectively ([Firefox bug 1648944](https://bugzil.la/1648944)).

#### Media, WebRTC, and Web Audio

- Access to audio output devices, like speakers and headphones, is now protected by the [speaker-selection](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Permissions-Policy/speaker-selection) feature policy ([Firefox bug 1577199](https://bugzil.la/1577199)).

### WebDriver conformance (Marionette)

- Improved support for the `webSocketUrl` capability, which now returns the WebDriver BiDi websocket URL if `true` was passed and if BiDi is supported. ([Firefox bug 1692984](https://bugzil.la/1692984)).

## Changes for add-on developers

- Support for `cookieStoreId` is added to [`downloads.download`](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/downloads/download), [`downloads.DownloadQuery`](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/downloads/DownloadQuery), and [`downloads.DownloadItem`](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/downloads/DownloadItem). The addition to the types [`downloads.DownloadQuery`](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/downloads/DownloadQuery) and [`downloads.DownloadItem`](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/downloads/DownloadItem) provides support in [`downloads.search`](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/downloads/search) and [`downloads.erase`](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/downloads/erase). Web extensions can now associate downloads with specific cookie stores, such as container tabs ([contextual identities](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/Work_with_contextual_identities)). ([Firefox bug 1669566](https://bugzil.la/1669566))

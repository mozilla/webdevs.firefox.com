Firefox 24 was released on September 17, 2013. This article lists key changes that are useful not only for web developers, but also Firefox and Gecko developers as well as add-on developers.

## Changes for web developers

### Developer Tools

- The Network inspector now lets you filter by content type (CSS/image/font etc.) and see the relevant size and load times.
- The DevTools options panel to the left lets you disable/enable JavaScript temporarily.
- Extension developers may use the new [Browser Console](https://mihai.sucan.ro/mihai/blog/the-browser-console-is-replacing-the-error-console/) for Chrome-level scripts (Replaces Error Console).
- The source map syntax has been changed to use `//#` instead of `//@` ([Firefox bug 870361](https://bugzil.la/870361)).

### CSS

- The two values `-moz-zoom-in` and `-moz-zoom-out` of the [`cursor`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/cursor) property have been unprefixed to `zoom-in` and `zoom-out` ([Firefox bug 772153](https://bugzil.la/772153)).
- To match the specification, the keywords `not`, `only`, `and`, and `or` cannot be used as media types anymore ([Firefox bug 757554](https://bugzil.la/757554)).

### HTML

- The [`<track>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/track) element has been implemented behind the `media.webvtt.enabled` preference, and is disabled by default. ([Firefox bug 833385](https://bugzil.la/833385)).

### JavaScript

- [Arrow functions](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Functions/Arrow_functions) are no longer automatically in strict mode unless explicitly requested with `"use strict"` ([Firefox bug 852762](https://bugzil.la/852762)).
- The [`String.prototype.repeat`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/repeat) JS method has been implemented ([Firefox bug 815431](https://bugzil.la/815431)).
- The [`Set.prototype.values()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set/values), [`Set.prototype.keys()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set/values) and [`Set.prototype.entries()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set/entries) methods on [`Set`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set) objects have been implemented ([Firefox bug 869996](https://bugzil.la/869996)).

### DOM

- Support for the [`Range()`](https://developer.mozilla.org/en-US/docs/Web/API/Range/Range) constructor has been added ([Firefox bug 868999](https://bugzil.la/868999)).
- Support for the [`Text()`](https://developer.mozilla.org/en-US/docs/Web/API/Text/Text) constructor has been added ([Firefox bug 869000](https://bugzil.la/869000)).
- Support for the [`Comment()`](https://developer.mozilla.org/en-US/docs/Web/API/Comment/Comment) constructor has been added ([Firefox bug 869006](https://bugzil.la/869006)).
- Support for the [`DocumentFragment()`](https://developer.mozilla.org/en-US/docs/Web/API/DocumentFragment/DocumentFragment) constructor has been added ([Firefox bug 869002](https://bugzil.la/869002)).
- The [`FocusEvent`](https://developer.mozilla.org/en-US/docs/Web/API/FocusEvent) interface has been implemented ([Firefox bug 855741](https://bugzil.la/855741)).
- Support for the [`ChildNode.remove()`](https://developer.mozilla.org/en-US/docs/Web/API/Element/remove) method has been added ([Firefox bug 856629](https://bugzil.la/856629)).
- The WebVTT interfaces related to the [`<track>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/track) element, [`HTMLTrackElement`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLTrackElement), [`TextTrack`](https://developer.mozilla.org/en-US/docs/Web/API/TextTrack), [`TextTrackCue`](https://developer.mozilla.org/en-US/docs/Web/API/TextTrackCue), [`TextTrackList`](https://developer.mozilla.org/en-US/docs/Web/API/TextTrackList), and [`TextTrackCueList`](https://developer.mozilla.org/en-US/docs/Web/API/TextTrackCueList) have been implemented behind the `media.webvtt.enabled` property, defaulting to `false` ([Firefox bug 833385](https://bugzil.la/833385)).
- The [`Gamepad`](https://developer.mozilla.org/en-US/docs/Web/API/Gamepad) interface, and [`Navigator.getGamepads`](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/getGamepads) have been implemented behind the `dom.gamepad.enabled` property, defaulting to `false` ([Firefox bug 690935](https://bugzil.la/690935)).
- On desktop Firefox only, `HTMLCanvasElement.getContext()` can now take the `webgl` value, in addition to `experimental-webgl` ([Firefox bug 870232](https://bugzil.la/870232)).
- The non-standard method `mozLoadFrom()` of [`HTMLMediaElement`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement) has been removed ([Firefox bug 877135](https://bugzil.la/877135)).

### MathML

- The `dir` attribute for controlling directionality of formulas on e.g., [`<math>`](https://developer.mozilla.org/en-US/docs/Web/MathML/Reference/Element/math) or [`<mrow>`](https://developer.mozilla.org/en-US/docs/Web/MathML/Reference/Element/mrow) elements is now equivalent to using the [`direction`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/direction) CSS property.
- The equal sign ("=") is now [stretchable](https://developer.mozilla.org/en-US/docs/Web/MathML/Reference/Element/mo#stretchy).
- The `"updiagonalarrow"` value for the `notation` attribute on [`<menclose>`](https://developer.mozilla.org/en-US/docs/Web/MathML/Reference/Element/menclose) elements has been added.

## Changes for add-on and Mozilla developers

- Doc Shells have now the `allowMedia` attribute to disable media playing ([Firefox bug 759964](https://bugzil.la/759964)).
- Sherlock search plugins in the application directory or profile won't be loaded anymore ([Firefox bug 862143](https://bugzil.la/862143)).

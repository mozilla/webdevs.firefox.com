[To test the latest developer features of Firefox, install Firefox Developer Edition](https://www.firefox.com/en-US/channel/desktop/developer/) Firefox 48 was released on August 2, 2016. This article lists key changes that are useful not only for web developers, but also Firefox and Gecko developers as well as add-on developers.

## Changes for web developers

### Developer Tools

- The position of elements can now be changed within the content ([Firefox bug 1139187](https://bugzil.la/1139187)).
- Implemented [`console.clear()`](https://developer.mozilla.org/en-US/docs/Web/API/console/clear_static) to clear the console output ([Firefox bug 659625](https://bugzil.la/659625)).
- Added [HTTP log inspection to the Web Console](https://firefox-source-docs.mozilla.org/devtools-user/web_console/console_messages/index.html#viewing-network-request-details) ([Firefox bug 1211525](https://bugzil.la/1211525)).
- Added a [Firebug theme](https://firefox-source-docs.mozilla.org/devtools-user/tools_toolbox/index.html#choose-devtools-theme) ([Firefox bug 1244054](https://bugzil.la/1244054)).
- Added the [DOM Inspector](https://firefox-source-docs.mozilla.org/devtools-user/dom_property_viewer/index.html) ([Firefox bug 1201475](https://bugzil.la/1201475)).
- [Font inspector](https://firefox-source-docs.mozilla.org/devtools-user/page_inspector/ui_tour/index.html#fonts-view) has been enabled by default again ([Firefox bug 1280121](https://bugzil.la/1280121)).
- [Improved suggestions](https://firefox-source-docs.mozilla.org/devtools-user/page_inspector/how_to/examine_and_edit_css/index.html#edit-rules) for CSS properties ([Firefox bug 1168246](https://bugzil.la/1168246)).
- Cookies, localStorage and sessionStorage entries are editable via double-click ([Firefox bug 1231154](https://bugzil.la/1231154), [Firefox bug 1231179](https://bugzil.la/1231179), [Firefox bug 1231155](https://bugzil.la/1231155)).

### HTML

- The [`<details>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/details) and [`<summary>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/summary) elements have been activated by default on Nightly and Aurora (DevTools), but not on Beta or Release:
  - The default style for these elements has been adapted to match the spec ([Firefox bug 1258657](https://bugzil.la/1258657)).
  - The `toggle` event is now sent to the [`<details>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/details) element when this one is opened or closed ([Firefox bug 1225412](https://bugzil.la/1225412)).

- The [`meta`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/meta) attributes now also supports the `no-referrer-when-downgrade` and `origin-when-cross-origin` values ([Firefox bug 1178337](https://bugzil.la/1178337)).

### CSS

- The [`calc()`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/calc) has been improved to be closer to the specification:
  - [`calc()`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/calc) is now supported on the [`line-height`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/line-height) property ([Firefox bug 594933](https://bugzil.la/594933)).
  - Added support for nested CSS [`calc()`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/calc) ([Firefox bug 968761](https://bugzil.la/968761)).

- Our experimental implementation of CSS grids has been updated:
  - Fragmentation for grid layout has been implemented ([Firefox bug 1144096](https://bugzil.la/1144096)).
  - \[css-grid] Percentage tracks are now treated as `auto` if grid container size is indefinite ([Firefox bug 1264607](https://bugzil.la/1264607)).
  - [`<fieldset>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/fieldset) now supports grid and flex layouts ([Firefox bug 1230207](https://bugzil.la/1230207)).

- The `luminance` value for [`mask-mode`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/mask-mode) has been added; the `auto` value has been renamed to `match-source`, to match the spec ([Firefox bug 1228354](https://bugzil.la/1228354)).
- Interpolation of [`clip-path`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/clip-path) basic shapes in CSS animations and transitions is now supported ([Firefox bug 1110460](https://bugzil.la/1110460)).
- Support for horizontal-in-vertical (_tate-chu-yoko_) text has been added via the `all` value of the [`text-combine-upright`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/text-combine-upright) property ([Firefox bug 1097499](https://bugzil.la/1097499)).
- Support for the experimental [`color-adjust`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/print-color-adjust) property has been added, allowing pages to specify that background colors and images should be printed ([Firefox bug 1209273](https://bugzil.la/1209273)).
- The [`::first-letter`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::first-letter) pseudo-element now also matches punctuation characters of type Pd that precede or immediately follow the actual first letter; this is a new requirement of CSS Pseudo-element module level 4 ([Firefox bug 1260366](https://bugzil.la/1260366)).
- Several `-webkit` prefixed properties and values have been added for web compatibility, behind the preference `layout.css.prefixes.webkit`, defaulting to `false`:
  - [`-webkit-text-fill-color`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/-webkit-text-fill-color) ([Firefox bug 1247777](https://bugzil.la/1247777)).
  - [`-webkit-text-stroke`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/-webkit-text-stroke), [`-webkit-text-stroke-color`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/-webkit-text-stroke-color), [`-webkit-text-stroke-width`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/-webkit-text-stroke-width) ([Firefox bug 1248708](https://bugzil.la/1248708)).
  - `-webkit-background-clip` (as background-clip) text value ([Firefox bug 759568](https://bugzil.la/759568)).
  - `-webkit-box-direction`, `-webkit-box-orient` ([Firefox bug 1262049](https://bugzil.la/1262049).
  - The value `-webkit-inline-box` is now an alias of `inline-flex` on the [`display`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/display) property. ([Firefox bug 1257661](https://bugzil.la/1257661)).
  - `-webkit-flex-direction`, `-webkit-flex-wrap`, `-webkit-flex-flow`, `-webkit-order`, `-webkit-flex`, `-webkit-flex-grow`, `-webkit-flex-shrink`, `-webkit-flex-basis`, `-webkit-justify-content`, `-webkit-align-items`, `-webkit-align-self` and `-webkit-align-content` were added as aliases for the unprefixed properties and the values `-webkit-flex` and `-webkit-inline-flex` for the [`display`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/display) property as aliases for the unprefixed values ([Firefox bug 1274096](https://bugzil.la/1274096)).
  - Added `-webkit-box-flex`, `-webkit-box-ordinal-group`, `-webkit-box-align` and `-webkit-box-pack` properties and `-webkit-box` value to [`display`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/display) as aliases for modern [CSS Flexbox](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Flexible_box_layout/Use_cases) ([Firefox bug 1208635](https://bugzil.la/1208635)).

- The `text` value of [`background-clip`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/background-clip) is now available in all type of Firefox (and not only non-release builds) ([Firefox bug 1263516](https://bugzil.la/1263516)).
- The `absolute` value of [`position`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/position) properties on the top layer element ([Firefox bug 1236828](https://bugzil.la/1236828)).
- Added an internal-only syntax for [`@supports`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@supports) to detect pref ([Firefox bug 1259889](https://bugzil.la/1259889)).

### JavaScript

#### New APIs

- The [`String.prototype.padStart()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/padStart) and [`String.prototype.padEnd()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/padEnd) methods have been implemented ([Firefox bug 1260509](https://bugzil.la/1260509)).
- The ES2015 [`Symbol.unscopables`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Symbol/unscopables) and [`Array.prototype[Symbol.unscopables]`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/Symbol.unscopables) properties have been implemented ([Firefox bug 1054759](https://bugzil.la/1054759) and [Firefox bug 1258163](https://bugzil.la/1258163)).
- The ES2015 [`Symbol.isConcatSpreadable`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Symbol/isConcatSpreadable) symbol has been implemented ([Firefox bug 1041586](https://bugzil.la/1041586)).
- The ES2015 [`Array[Symbol.species]`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/Symbol.species) getter has been implemented ([Firefox bug 1165052](https://bugzil.la/1165052)).
- The ES2015 [`ArrayBuffer[Symbol.species]`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/ArrayBuffer/Symbol.species) getter and [`TypedArray[Symbol.species]`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/TypedArray/Symbol.species) getter have been implemented ([Firefox bug 1165053](https://bugzil.la/1165053)).
- The [`Intl.getCanonicalLocales()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/getCanonicalLocales) method of the ECMAScript Internationalization API draft has been implemented ([Firefox bug 1263040](https://bugzil.la/1263040)).

#### Deprecations and removals

- The deprecated [old Proxy API](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Deprecated_and_obsolete_features#proxy) (`Proxy.create` and `Proxy.createFunction()`) has been removed. Use the standard [`Proxy`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Proxy) object instead ([Firefox bug 892903](https://bugzil.la/892903)).
- The `String.prototype.contains()` method has been removed (it was deprecated since version 40). Use the [`String.prototype.includes()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/includes) method instead ([Firefox bug 1103588](https://bugzil.la/1103588)).
- The non-standard `RegExp.multiline` property (not [`RegExp.prototype.multiline`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/RegExp/multiline)) has been removed. Use the standard [m flag](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Regular_expressions#advanced_searching_with_flags) instead ([Firefox bug 1219757](https://bugzil.la/1219757)).
- The [`Object.prototype.__defineGetter__()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Object/__defineGetter__) and [`Object.prototype.__defineSetter__()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Object/__defineSetter__) methods can no longer be called at the global scope without any object. ([Firefox bug 1253016](https://bugzil.la/1253016)).

### Interfaces/APIs/DOM

#### DOM & HTML DOM

- Dropped the "Moz" prefix from the [`CSSKeyframeRule`](https://developer.mozilla.org/en-US/docs/Web/API/CSSKeyframeRule) and [`CSSKeyframesRule`](https://developer.mozilla.org/en-US/docs/Web/API/CSSKeyframesRule) interfaces ([Firefox bug 1256178](https://bugzil.la/1256178)).
- The `NavigatorConcurrentHardware` [mixin](https://developer.mozilla.org/en-US/docs/Glossary/Mixin) has been implemented, which adds the [`Navigator.hardwareConcurrency`](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/hardwareConcurrency) property to the [`Navigator`](https://developer.mozilla.org/en-US/docs/Web/API/Navigator) interface. This lets websites and apps get at least an approximation of how many processing cores are available to run [`Worker`](https://developer.mozilla.org/en-US/docs/Web/API/Worker)s in ([Firefox bug 1008453](https://bugzil.la/1008453)).
- The [`Node.isSameNode()`](https://developer.mozilla.org/en-US/docs/Web/API/Node/isSameNode) method, which was removed in Firefox 10, has returned after being added back into the specification after a lengthy absence ([Firefox bug 1256299](https://bugzil.la/1256299)).
- Firefox now returns proper exceptions instead of numbers when things go wrong during a call to [`Navigator.registerProtocolHandler()`](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/registerProtocolHandler).
- [`Element.animate()`](https://developer.mozilla.org/en-US/docs/Web/API/Element/animate) is now activated by default ([Firefox bug 1245000](https://bugzil.la/1245000)).
- The two methods [`Element.insertAdjacentText()`](https://developer.mozilla.org/en-US/docs/Web/API/Element/insertAdjacentText) and [`Element.insertAdjacentElement()`](https://developer.mozilla.org/en-US/docs/Web/API/Element/insertAdjacentElement) have been implemented ([Firefox bug 811259](https://bugzil.la/811259)).
- [`Document.scrollingElement`](https://developer.mozilla.org/en-US/docs/Web/API/Document/scrollingElement) got enabled by default ([Firefox bug 1265032](https://bugzil.la/1265032)).
- `Node.localName`, `Node.namespaceURI` and `Node.prefix` were moved to the [`Element`](https://developer.mozilla.org/en-US/docs/Web/API/Element) and [`Attr`](https://developer.mozilla.org/en-US/docs/Web/API/Attr) APIs ([Firefox bug 1055776](https://bugzil.la/1055776)).
- Per the latest specification, the values of [`KeyboardEvent.code`](https://developer.mozilla.org/en-US/docs/Web/API/KeyboardEvent/code) returned for the following keys have been changed see ([Firefox bug 1264150](https://bugzil.la/1264150)):
  - `"OSLeft"` and `"OSRight"` are now `"MetaLeft"` and `"MetaRight"`.
  - `"VolumeDown"`, `"VolumeUp"`, and `"VolumeMute"` are now `"AudioVolumeDown"`, `"AudioVolumeUp"`, and `"AudioVolumeMute"`.
  - `"IntlHash"` has been removed.
  - All keys whose `code` values were reported as "" in earlier versions of Firefox are now reported as "Unidentified".

#### Canvas 2D

- The [`CanvasRenderingContext2D.ellipse()`](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/ellipse) method has been implemented ([Firefox bug 910138](https://bugzil.la/910138)).

#### WebRTC

- The two methods [`MediaStream.clone()`](https://developer.mozilla.org/en-US/docs/Web/API/MediaStream/clone) and [`MediaStreamTrack.clone()`](https://developer.mozilla.org/en-US/docs/Web/API/MediaStreamTrack/clone) have been implemented ([Firefox bug 1208371](https://bugzil.la/1208371)).
- The `iceRestart` entry is now supported in the `RTCOfferOptions` code dictionary, allowing [`createOffer()`](https://developer.mozilla.org/en-US/docs/Web/API/RTCPeerConnection/createOffer) to be used to request ICE restarts ([Firefox bug 906986](https://bugzil.la/906986)).
- The [`RTCPeerConnection.createOffer()`](https://developer.mozilla.org/en-US/docs/Web/API/RTCPeerConnection/createOffer) method now prefers the VP9 video codec by default; previously VP8 was preferred ([Firefox bug 1242324](https://bugzil.la/1242324).
- WebM/VP8 video that includes video resolution changes that has been recorded using [`MediaRecorder`](https://developer.mozilla.org/en-US/docs/Web/API/MediaRecorder) can now be played back successfully.

#### Others

- The [Web Crypto API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Crypto_API) is now available in [Web workers](https://developer.mozilla.org/en-US/docs/Web/API/Web_Workers_API) ([Firefox bug 842818](https://bugzil.la/842818)).
- The [`CustomEvent`](https://developer.mozilla.org/en-US/docs/Web/API/CustomEvent) interface is now available in [Web Workers](https://developer.mozilla.org/en-US/docs/Web/API/Web_Workers_API) ([Firefox bug 1003432](https://bugzil.la/1003432)).
- The `DOMApplicationsManager.getNotInstalled()` method has been removed ([Firefox bug 1255036](https://bugzil.la/1255036)).
- Several Firefox OS APIs that were erroneously exposed to the Web have now been hidden as they should have been — `mozContact`, `MozContactChangeEvent`, `navigator.mozContacts`, `MozPowerManager`, `MozSettingsEvent` (see [Firefox bug 1043562](https://bugzil.la/1043562), [Firefox bug 1256414](https://bugzil.la/1256414), and [Firefox bug 1256046](https://bugzil.la/1256046)).
- Support for UTF-16 has been removed from [`TextEncoder`](https://developer.mozilla.org/en-US/docs/Web/API/TextEncoder) ([Firefox bug 1257877](https://bugzil.la/1257877)).
- [`RTCStatsReport`](https://developer.mozilla.org/en-US/docs/Web/API/RTCStatsReport) is now a true `maplike` interface: in addition to [`forEach()`](https://developer.mozilla.org/en-US/docs/Web/API/RTCStatsReport/forEach), [`get()`](https://developer.mozilla.org/en-US/docs/Web/API/RTCStatsReport/get), and [`has()`](https://developer.mozilla.org/en-US/docs/Web/API/RTCStatsReport/has), the methods [`entries()`](https://developer.mozilla.org/en-US/docs/Web/API/RTCStatsReport/entries), [`values()`](https://developer.mozilla.org/en-US/docs/Web/API/RTCStatsReport/values), [`keys()`](https://developer.mozilla.org/en-US/docs/Web/API/RTCStatsReport/keys), as well as the [`size`](https://developer.mozilla.org/en-US/docs/Web/API/RTCStatsReport/size) getter have been implemented ([Firefox bug 906986](https://bugzil.la/906986)).
- The [`Request.cache`](https://developer.mozilla.org/en-US/docs/Web/API/Request/cache) property has been added allowing you to control the cache behavior ([Firefox bug 1120715](https://bugzil.la/1120715)).
- Handling of dead keys on Mac OS X has been changed to work the same as other platforms; they no longer fire a [`keypress`](https://developer.mozilla.org/en-US/docs/Web/API/Element/keypress_event) event when no text is generated when the focused element isn't editable (when the focused element is editable, dead key causes composition events instead of keyboard events on Mac OS X). Also, like on other platforms, the value of [`KeyboardEvent.key`](https://developer.mozilla.org/en-US/docs/Web/API/KeyboardEvent/key) is now `"Dead"` for dead key presses which don't generate text in other situations.

## HTTP

- Support for the [`Upgrade-Insecure-Requests`](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Upgrade-Insecure-Requests) header has been added ([Firefox bug 1243586](https://bugzil.la/1243586)).
- The [`block-all-mixed-content`](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/block-all-mixed-content) CSP directive has been implemented ([Firefox bug 1122236](https://bugzil.la/1122236))

## Changes for add-on and Mozilla developers

- The Social Worker API has been removed.
- Added the `-moz-bool-pref()` [CSS](https://developer.mozilla.org/en-US/docs/Web/CSS) [`@supports`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@supports) function to allow hiding portions of chrome stylesheets behind boolean preferences. ([Firefox bug 1259889](https://bugzil.la/1259889))
